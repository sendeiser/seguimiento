# 🎓 Notyx Edu — Plataforma de Seguimiento Académico Gamificada

**Notyx Edu** es una solución integral para instituciones educativas que combina la gestión ágil del aula para docentes con mecánicas de videojuegos (XP, niveles, cartas Pokémon coleccionables, minijuegos y tienda de skins) para motivar el aprendizaje de los estudiantes.

---

## 🚀 Inicio Rápido

### Requisitos
* **Node.js**: v18+ y npm
* **Supabase**: Proyecto configurado con credenciales en `.env`

### Instalación y Ejecución Local
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo web
npm run dev
```

### Aplicación Móvil para Estudiantes
El proyecto incluye una aplicación Android nativa construida en Kotlin y Jetpack Compose dentro del directorio [`android-app/`](file:///c:/Users/TinChoX/Desktop/COSAS%20DE%20PROGRAMACION/Proyectos%20React-Node/Seguimiento%20Alumnos/seguimiento/android-app).
